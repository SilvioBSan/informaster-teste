2 — Baixar e publicar

  1. Publique o index.html atualizado no lugar do atual (GitHub Pages ou Netlify, com a pasta assets completa junto).
  2. Guarde o produtos.json junto da loja, como base do catálogo.
  3. Se trocar foto de produto, o arquivo da foto deve se chamar assets/<id em minúsculas>.webp (ex.: assets/pap-001.webp).
  4. Não suba este painel com botão Publicar para o site oficial sem aprovação — o protótipo é só para o teste.

3 — Backup e restauração

Restaurar o catálogo não apaga os pedidos. Apagar os dados locais remove produtos editados, pedidos e o PIN deste navegador.
